# USB-SCAN

## Présentation

USB-SCAN est un dépôt consacré à l'étude de la technologie USB (Universal Serial Bus).

L'objectif de ce dépôt est de rassembler des informations sur le fonctionnement et l'évolution de la technologie USB.

## Objectif

L'objectif de USB-SCAN est d'étudier la technologie USB, son évolution, ses différents connecteurs, ses versions, ses débits et ses principales fonctionnalités.

Le projet permet de rassembler, organiser et présenter ces informations de manière claire et accessible.

## Contenu du dépôt

Ce dépôt présente notamment :

- les différentes versions de l'USB ;
- les protocoles USB ;
- les types de connecteurs ;
- les vitesses de transfert ;
- l'alimentation électrique ;
- les principales utilisations de l'USB ;
- les différences entre USB 2.0, USB 3.x et USB4.

## Activité du dépôt

L'activité du dépôt consiste à rechercher, organiser et présenter des informations techniques sur la technologie USB.

Le Wiki permet de détailler les différentes notions et de compléter les informations présentées dans le README.

[Accéder au Wiki USB-SCAN](https://github.com/kissoulilice-maker/USB-SCAN/wiki)

## Sources

Les informations techniques sont notamment vérifiées à partir de la documentation officielle de l'USB Implementers Forum (USB-IF).
